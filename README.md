# SX1262-SDR

Receive-only research workspace for the Semtech SX1262 on the Heltec WiFi LoRa 32 V4, using a Pluto-compatible AD9361 SDR for attenuated conducted RF tests.

**Status:** Initial repository bootstrap. The research and test scaffold is prepared on `chatgpt/sx1262-rx-probe` as a proposed change, not verified hardware firmware.

Do not transmit or connect two RF TX/RX ports without a verified attenuated signal path. The published experimental tuning windows do not establish calibrated RF sensitivity or useful reception at every frequency.
